📊 Bank Statement to Excel

Upload a PDF bank statement — extract every transaction, auto-label each one with a Remark category, and export to Excel

1. Upload Statement (PDF)

📁
Click to select or drag & drop a PDF bank statement
Text-based PDF statements work best (e.g. Hong Leong Bank current account style). Scanned/image-only PDFs may not extract cleanly.

2. Review Transactions & Remarks

One rule per line, format: keyword = Category label. Rules are checked top to bottom — the first keyword found in a transaction's description wins. Edit, add, or remove rules, then click "Re-apply to Table".

💾 Save to Database

Sends only the Date and Description of the selected rows to your Railway PostgreSQL database via the small API in bank-statement-api/. Paste your Railway API URL once — it's remembered in this browser.

3. Generate Payment Voucher

Builds a printable payment voucher from the transaction(s) you ticked above — useful for multiple invoice lines paid to the same payee.
